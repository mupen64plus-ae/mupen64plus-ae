===================================================================
PRÓXIMOS PASOS (ejecuta en orden)
===================================================================

1. COPIA EL PROYECTO A TU MÁQUINA LINUX/WSL2/MAC
   scp -r n64-gyro-emulator/ usuario@maquina-linux:~/  # o copia manual

2. VERIFICA ENTORNO
   cd n64-gyro-emulator
   chmod +x scripts/*.sh build.sh
   ./scripts/verify-env.sh
   # Corrige errores si los hay

3. CONFIGURA PATHS LOCALES
   cp local.properties.example local.properties
   nano local.properties  # Ajusta sdk.dir y ndk.dir

4. GENERA KEYSTORE (para release)
   ./scripts/gen-keystore.sh
   # Guarda las contraseñas que te muestre

5. BUILD DE PRUEBA (debug)
   ./build.sh debug
   # Resultado en build-outputs/debug/app-debug.apk

6. INSTALA EN MÓVIL Y TESTEA
   adb install build-outputs/debug/app-debug.apk
   ./scripts/test-gyro-on-device.sh

7. SUBE A GITHUB
   git init
   git add .
   git commit -m "Initial commit: N64 Gyro Emulator"
   git branch -M main
   git remote add origin https://github.com/TU_USUARIO/n64-gyro-emulator.git
   git push -u origin main

8. CONFIGURA GITHUB SECRETS (Settings → Secrets → Actions)
   KEYSTORE_BASE64, KEYSTORE_PASSWORD, KEY_ALIAS, KEY_PASSWORD
   (valores que te mostró gen-keystore.sh)

9. BUILD AUTOMÁTICO EN GITHUB
   - Push a main → compila debug+release, sube artifacts
   - Tag v1.0.0 → crea Release en GitHub con AAB listo para Play Store

10. PUBLICA EN PLAY STORE
    - Play Console → Crear app → Internal testing → Subir app-release.aab
    - Completa ficha (icono, screenshots, política privacidad)
    - En descripción: "Código fuente: https://github.com/TU_USUARIO/n64-gyro-emulator (GPL v3)"
